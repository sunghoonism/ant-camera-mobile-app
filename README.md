# Ant Camera

태그 기반의 사진 관리 카메라 앱입니다. (조용한 카메라)

## 기능

- 사진 촬영 및 저장
- 태그 시스템으로 사진 분류
- 저장 경로 사용자 지정 가능
- 위치 정보 저장 옵션
- 권한 관리(카메라, 저장소)

## 기본 태그

- 개인
- 집
- 직장
- 학교
- 그밖에

## 데이터 관리

- SharedPreferences를 사용하여 사용자 설정 저장
- 태그별 폴더 자동 생성
- 사진 파일명에 타임스탬프 추가(ANT_시간.jpg 형식)
- 기본 저장소 접근 실패 시 앱 내부 저장소 사용

## 설치 및 실행

```bash
flutter pub get
#flutter run
#flutter에서 작동하지 않으므로 안드로이드 스튜디오에서 실행 필요요
```

## 필요한 권한

- 카메라
- 저장소 접근 권한
