# Ant Camera

태그 기반의 사진 관리 카메라 앱입니다.

## 기능

- 카메라로 사진 촬영
- 사진 촬영 시 태그 지정 가능
- 사용자 지정 태그 추가 기능
- 태그 정보와 함께 사진 저장

## 기본 태그

- 개인
- 집
- 직장
- 학교

## 개발 환경

- Flutter
- CameraAwesome 패키지

## 설치 및 실행

```bash
flutter pub get
#flutter run
#flutter에서 작동하지 않으므로 안드로이드 스튜디오에서 실행 필요요
```

## 필요한 권한

- 카메라
- 저장소 접근 권한
